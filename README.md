# Supermercado Alem - Landing Page

Landing page oficial de **Supermercado Alem ("Tu comercio amigo")**.

## Características
- Diseño moderno, responsivo y adaptado para móviles y escritorio.
- Integración directa con WhatsApp para atención al cliente y pedidos.
- Optimizado para SEO con etiquetas semánticas y metadatos.
- Despliegue automático en GitHub Pages.

## Ejecución Local
Puedes iniciar el servidor local en Windows haciendo doble clic en `iniciar_servidor.bat` o ejecutando:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Luego abre tu navegador en [http://localhost:8080/](http://localhost:8080/).
